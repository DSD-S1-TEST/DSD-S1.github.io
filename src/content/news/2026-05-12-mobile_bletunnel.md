# BLE Tunnel Android version v0.0.1 has been completed
We are excited to announce the completion of the initial production release of the Bluetooth Low Energy (BLE) tunnel for Android, version v0.0.1. This release includes the implementation of the asynchronous BLE tunnel architecture, a dual-protocol decoding engine, and a fault-tolerant multi-sensor data acquisition system.
